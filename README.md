# GafiGoogle

Extensão Manifest V3 para Chromium que adiciona uma camada visual clean e smooth ao Google.

## Incluído

- Entrada e transições suaves
- Resultados com stagger e scroll reveal
- Hover e microinterações
- Barra de pesquisa polida
- Loading bar discreta
- Click ripple
- Cursor glow
- Partículas opcionais
- Glow RGB opcional
- Glassmorphism opcional
- Microanimação do logo
- Perfis Clean / Gaming / RGB
- Popup de definições com armazenamento sincronizado
- Nova página de separador personalizada

## Instalação local

1. Abre a página de extensões do Chrome.
2. Ativa Modo de programador.
3. Escolhe Carregar sem compactação.
4. Seleciona a pasta deste repositório.

A extensão não altera as pesquisas do Google; aplica apenas a camada visual e as animações aprovadas.
